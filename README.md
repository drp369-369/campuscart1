# 🎓 CampusCart — Phase 1: Student Marketplace Landing Page

CampusCart is a modern, student-only peer-to-peer marketplace designed specifically for university campuses. It enables verified students to easily buy and sell pre-loved textbooks, electronics, scientific calculators, dorm furniture, handwritten notes, and campus essentials safely within campus grounds.

---

## 🚀 Phase 1 Overview
Phase 1 focuses entirely on delivering a **pixel-perfect, startup-grade landing page and frontend foundation** without any external dependencies or backend requirements.

### Key Sections:
1. **Glassmorphic Navigation Bar** — Brand logo, navigation anchors, quick actions (*Sell an Item*, *Sign In*), and mobile navigation drawer.
2. **Hero Section** — High-impact typography, campus live search bar with quick filters, primary/secondary CTAs, interactive floating campus deal mockup, and live campus metrics.
3. **Marketplace Categories** — Interactive cards for Books, Electronics, Calculators, Dorm Furniture, Study Materials, and Student Essentials with live category filtering.
4. **Featured Listings Preview** — Realistic demo marketplace listings with condition badges, verified student tags, pricing, and item preview modal.
5. **How CampusCart Works** — 3-step campus exchange workflow (01: Find, 02: Connect, 03: Exchange Safely).
6. **Student Trust & Safety** — Dedicated value proposition highlighting campus-only verification, zero shipping fees, circular economy, and safe exchange zones.
7. **Seller Call-to-Action (CTA)** — High-converting student seller banner with community proof.
8. **Responsive Footer** — Comprehensive campus navigation, verified hubs, and copyright.

---

## 🛠️ Technology Stack
- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom design tokens, glassmorphism, micro-animations, and responsive CSS Grid/Flexbox layouts.
- **Vanilla JavaScript**: Real-time listing search & filter, mobile drawer, modal previews, and toast notification system.
- **No external frameworks, libraries, or build tools required.** Simply open `index.html` in any modern web browser.

## 📦 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in your browser, or serve via any static file server:
   ```bash
   # Optional python local server
   python -m http.server 3000
   ```
3. Open `http://localhost:3000` in your web browser.
